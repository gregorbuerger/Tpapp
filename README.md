# Tanken & Parken – Pilot v2.4

Mobile-first PWA für das Pilotgebiet Ottobeuren–Memmingen.

## v2.4
- Keine Demo-Tankdaten und keine simulierten Belegungen.
- Memminger Parkhäuser mit veröffentlichten Kapazitäten, Öffnungszeiten, Einfahrtshöhen und Gebühren ergänzt.
- „Jetzt geöffnet“ / „Jetzt geschlossen“ wird lokal aus den veröffentlichten Öffnungszeiten berechnet.
- Updatefunktion und Cache-Strategie aus v2.3 fortgeführt; Cache-Version v2.4.
- Tankstellenansicht bleibt bis zur Aktivierung des Tankerkönig-Keys ohne erfundene Daten.

Quellen der Parkhausdaten: Stadtwerke Memmingen / Stadt Memmingen; Stand 02.10.2026.
